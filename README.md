# Ֆերմա-Տորիչելիի Խնդիրը նորմավորված տարածություններում

Ավարտական աշխատանքի LaTeX ֆայլերը և **Julia** լեզվով գրված թվային ու գրաֆիկական օրինակները՝ նվիրված Ֆերմա-Տորիչելիի խնդիրը նորմավորված տարածություններում։
